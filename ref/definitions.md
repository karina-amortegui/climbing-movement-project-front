# BrowserRouter
Manages browser-based routing for the React app.

# Routes
Conatians the route rules.

# Route
Maps a url pattern to a component.

# Link
Navigates the user to another url without a traditional full-page reload.

# useParams
Extracts dynamic values like id from the url.

# Outlet
Provides the lcoation inside a shared layout where the matched child component renders.

# Nested Routes
Nesting establishes the parent/child relationship. <Outlet /> is where the child gets rendered inside the parent.
